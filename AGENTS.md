# AGENTS.md

This file provides guidance to AI agents when working with code in this repository.

## Commands

```bash
pnpm dev                    # Vite dev server on :8080
pnpm build                  # Production build
pnpm test                   # Run tests (vitest run)
pnpm typecheck              # Type check (tsc --noEmit)
pnpm check                  # Format (Oxfmt) + lint (Oxlint) with auto-fix
```

## Architecture

Full-stack React app using **TanStack Start** (React 19 + Vite + Nitro): type-safe file-based routing via TanStack Router, with TanStack Query integrated into SSR through `@tanstack/react-router-ssr-query`.

### Key directories

- `src/routes/` — File-based routes (TanStack Router, auto-generates `routeTree.gen.ts`)
- `src/components/ui/` — shadcn/ui primitives (Base Vega style, Lucide icons)
- `src/lib/` — App providers and utilities

### Auto-generated files (do not edit)

- `src/routeTree.gen.ts` — Regenerated by TanStack Router plugin

### Environment

Only `VITE_*` vars are exposed to the client (Vite convention). Configured in `.env.local`.
